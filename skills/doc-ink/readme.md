# 🖋️ doc-ink
**"Doc for structure, Ink for soul."**  
 *(结构归于文档，灵魂付于笔墨)*

## 📖 简介

`doc-ink` 是一个全能型跨语境内容创作 Skill。它打破了“技术文档”与“创意写作”的边界，专为需要同时驾驭**硬核技术**、**自媒体网感**与**深度/玄学思考**的创作者打造。

无论你是要输出一篇逻辑严密的 CSDN 技术博客、一篇爆款小红书种草笔记，还是一篇探讨运势与代码的公众号玄学长文，`doc-ink` 都能精准切换文风，让墨水（Ink）在文档（Doc）的框架内自由流淌。

---

## ✨ 核心特性

- ** 多栖风格引擎**：内置“极客严谨”、“网感种草”、“深邃玄学”等多种文风预设，拒绝 AI 味的千篇一律。
- ** 平台原生适配**：
    - **CSDN/知乎/掘金**：标准 Markdown 排版，代码高亮，逻辑清晰，目录结构完整。
    - **小红书**：爆款标题、丰富的 Emoji、痛点引入、吸睛排版与精准 Hashtag。
    - **公众号**：沉浸式长文结构，金句提炼，适合深度阅读与情绪共鸣。
- **⚖ 理性与感性平衡**：写技术时保证逻辑闭环无 Bug，写玄学/自媒体时保证情绪价值与“灵气”。

---

## 🎯 支持场景与 Prompt 示例

### 💻 场景一：开发者技术文档 (CSDN / 知乎 / 掘金)
**风格**：严谨、结构化、图文并茂、代码规范。

```text
/doc-ink 
平台：CSDN
主题：深入理解 React 18 的 Concurrent Mode
要求：
1. 包含引言、核心概念、代码示例、性能对比和总结。
2. 代码需包含详细注释。
3. 语气专业客观，适合中高级开发者阅读。
```

### 📕 场景二：自媒体种草/干货 (小红书 / 微博)
**风格**：吸睛、情绪化、碎片化、强互动。

```text
/doc-ink 
平台：小红书
主题：程序员防脱发/护肝好物分享（或：高颜值机械键盘推荐）
要求：
1. 写 5 个带痛点的爆款标题供我选择。
2. 正文多用 Emoji，分段要短，突出“使用感受”和“颜值”。
3. 结尾引导评论互动，并生成 5-8 个相关 Tag。
```

### 🔮 场景三：公众号深度/玄学文档 (微信公众号 / 个人博客)
**风格**：深邃、意识流、结合传统玄学与现代生活、引人深思。

```text
/doc-ink 
平台：微信公众号
主题：2026丙午年“九紫离火运”对程序员职业发展的影响
要求：
1. 结合传统命理“离火”意象（如虚拟、科技、精神）与 IT 行业现状（AI 爆发、裁员焦虑）。
2. 给出具体岗位的运势建议（如前端、算法、产品）。
3. 文风要带点哲学意味和神秘感，金句频出，适合朋友圈转发。
```

## ⚙️ 进阶参数 (Configuration)

在调用 `doc-ink` 时，你可以通过以下参数微调输出：

| 参数名 | 说明 | 可选值 | 默认值 |
| :--- | :--- | :--- | :--- |
| `--tone` | 设定文章基调 | `professional` (专业), `casual` (轻松), `mystic` (玄妙), `humorous` (幽默) | 自动推断 |
| `--length` | 控制文章篇幅 | `short` (小红书/短平快), `medium` (常规博客), `long` (深度长文) | `medium` |
| `--no-code` | 强制不输出代码块 | `true` / `false` | `false` |
| `--hook` | 强化开头吸引力 (适合自媒体) | `true` / `false` | 自动推断 |

---

## 💡 最佳实践建议

1. **提供“骨架”**：在 Prompt 中先给出你的核心观点或大纲，让 `doc-ink` 负责“填肉”和“润色”，效果比完全让它盲写要好得多。
2. **指定受众**：明确告诉它“读者是刚入门的小白”还是“有 5 年经验的架构师”，或者是“对玄学感兴趣的互联网打工人”。
3. **迭代修改**：如果第一版不够“玄”或不够“技术”，可以直接回复：“把第二段的语气改得更神秘一点”或“给第三段加个具体的代码例子”。
